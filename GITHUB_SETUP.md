# Publish and submit FlashGuard

1. Sign in to GitHub as `Cierijr`.
2. Choose **New repository**. Name it `FlashGuard`, describe it as `IST440W local video flash review prototype`, select **Public**, and create it.
3. Choose **uploading an existing file** or **Add file → Upload files**.
4. Upload all files from the extracted FlashGuard folder directly to the repository root. Upload the files, not just the ZIP. Commit the changes.
5. The expected link is https://github.com/Cierijr/FlashGuard if you use that exact name. This link is only valid after creation; it is not evidence that publishing has happened.
6. Open the repository link in a signed-out/private browser window and confirm its code and README are visible.
7. Download a fresh ZIP from the public repository on another computer. Extract it, open `index.html`, and analyze a supported local video using only the README instructions.
8. Submit the repository URL in the course assignment's link field. This is the code repository link, separate from the hosted prototype URL.

If you create the empty repository and give its URL to ChatGPT, the connected GitHub integration can be used to upload the prepared text files if it has write access to that repository. Never share passwords or access tokens in chat.
